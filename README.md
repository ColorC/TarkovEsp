# TarkovEsp — SPT 5.0.0 preview

SPT 5 IL2CPP overlay with player names, boxes and skeletons. This is a standalone local implementation: the original repository has no upstream remote and its initial commit is a new project scaffold. It is published as an independent repository rather than assigned an unrelated upstream fork lineage.

这是已在本地游戏中目测确认位置和性能的版本，其他版本与模组组合仍需验证，按实验预览版发布。

- [Compiled downloads](https://github.com/ColorC/TarkovEsp/releases)
- [Gameplay demo with Pit FireTeam](https://github.com/ColorC/SPT-PitFireTeam/releases/download/v0.10.3-spt5-preview.1/spt5-pitfireteam-wedge-demo-720p30.mp4)

## Target and install

Tested with EFT **1.1.5.47242 IL2CPP**, SPTushonka **5.0.0 BEM ec15a4**, BepInEx 6 be.788 and the compatible runtime used by the [Pit FireTeam preview](https://github.com/ColorC/SPT-PitFireTeam/blob/spt5-preview/docs/SPT5-PREVIEW.md). Other builds and stock runtime combinations are not guaranteed.

Extract the release ZIP into the game directory. It installs only `BepInEx/plugins/TarkovEsp/TarkovEsp.dll`; game files and user saves are not included. **Insert** toggles drawing. Configuration is generated at `BepInEx/config/codex.lilith.tarkovesp.cfg`.

Default projection rate is 30 Hz (configurable 5–60). Target discovery is cached, names/boxes have a 64-target budget, and skeletons are limited to 16 targets within 80 m. Lower these budgets if needed. Camera/display mapping, bounds and bone placement were checked against the game view and separately reviewed; this is visual acceptance on one setup, not a numerical zero-error guarantee or universal performance benchmark.

The released DLL is the exact visually accepted build (SHA256 `dc77b2ee1ed56cb501d63c1a6a34bd645a073a83c61bacffcc28135f81f78430`). Source C# is unchanged from that build; local project-path defaults were removed for portability.

## Build

Use .NET SDK 10 with .NET 6 targeting support, and the interop assemblies generated by your compatible installed game:

```powershell
dotnet build ./TarkovEsp.csproj -c Release -p:ClientRuntimeRoot='D:\Games\SPT5'
```

Package only `bin/Release/net6.0/TarkovEsp.dll`. Never copy game/interoperability DLLs from the build output into a public release. The project marks dependency references as non-copying.
